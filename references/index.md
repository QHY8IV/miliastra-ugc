## 0. 怎么在这 341 篇里找东西（先看这节）

语料文件名格式固定为 **`<条目id>_<标题>.md`**（例：`mhlaj0r9bldi_信号.md`）。所以知道标题就能直接命中。四个手段，按顺序用：

**① 查总目录（最权威）** —— `AGENTS.md` 在语料根，是全库条目总表，每条都有「标题：一句话说明 | 关键词」。先在里面搜关键词，拿到条目标题。

**② 按标题搜文件名** —— 拿到标题后（或只有一个模糊的词时），直接按文件名搜。中文标题可以直接搜：

```powershell
Get-ChildItem <语料根> -Recurse -Filter "*地形*.md" | Select-Object -ExpandProperty FullName
```

**③ 用精确路径** —— 只有 §1 列出的高频入口是**逐条验存过**的。§2 以后只给「搜什么词 + 大概率落在哪个目录」，**不要凭记忆拼路径**（拼错会静默指向不存在的文件）。§2–§6 里出现的编号（如 `2.6`、`3.10`）是**教程序号、不是路径**——拿它去用手段②搜标题。

**④ 同义词一次搜全（踩过坑，别省这一步）** —— 同一件事在语料里常有两三个叫法。**只搜一个词会漏掉核心组件**，而漏掉的后果不是答得糙，是**给出一套方向就错的方案**。

> **实测教训（已用受控对照复现）**：`计时器` 与 `定时器` **互相都不是对方的子串**（首字 `计` ≠ `定`）。搜 `计时器` **永远返回不了** `定时器` 那 3 篇——而「每秒采样一次剩余时间写进变量」这一环，**只有 `定时器` 能做**，漏掉它整条采样链就写不出来。
>
> **反过来别过度警惕**：`全局计时器` 只是 `计时器` 的**子串**，搜 `计时器` 就能命中，不必为它换词。真正要换的是**字面不重叠**的那些：`计时器`↔`定时器`、`背包`↔`道具`。

**⚠️ 两个检索通道不一样，别拿同一个词硬搜**：

| 你在想 | 按文件名搜（手段②） | 若 0 命中，改查总目录关键词（手段①） |
|---|---|---|
| 计时 / 时间 | `计时器` `定时器` `全局计时器` `时间` | `倒计时` ← **已验证：文件名 0 命中**，只存在于 `AGENTS.md` 关键词 |
| 道具经济 | `道具` `物品` `背包` `掉落物` `装备` `货币` `商店` `资源系统` | 同上方法 |
| 界面 | `界面控件` `控件组` `界面布局` | 同上方法 |
| 逻辑编排 | `节点图` `事件` `执行` `查询` `流程控制` `信号` | 同上方法 |
| 结算与胜负 | `结算` `关卡结算` `竞技段位` | 同上方法 |

## 7. 用法纪律

1. **先查本技能的本地速查（`references/api/*`、`lua-ui-playbook.md`），再回语料。** 前者是逐字校对过并带实测纠正的，后者是镜像原文。
2. **引用时标出处**：语料文件路径 + 抓取时间。不要把自己的推断说成官方文档。
3. **§1 之外的路径用搜的，不要凭记忆拼。** 文件名是 `<条目id>_<标题>.md`，搜标题即可。
4. **不要凭文件大小判断重要性**——很多条目只有几百字节，是因为正文在别处。
5. **`official/guide/` 与 `official/tutorial/` 是两套根**，同一主题可能在两边都有；**两处都搜一遍**再下结论。
6. 语料与实测冲突时，**实测优先**，并把冲突记回 `references/api/runtime-contract.md` 的「尚未确认」一节。
