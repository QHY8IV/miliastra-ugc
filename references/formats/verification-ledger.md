# 验证台账

本技能的每项文件能力，分两层验证：

- **离线**：用 50 个官方样本 + 自检（`node scripts/check-gia-gil.mjs --selftest`，13 项）。已完成，可重复。
- **真机**：把产物导入编辑器确认游戏接受。**尚未做**——这是我们没有的东西，需要用户帮忙。

真机结果请按 `README.md` §6 的流程做，然后**回来改这张表**：把「待验证」改成「✓ 日期 / 编辑器版本」或「✗ 现象」。
一项能力只有在真机 ✓ 之后，才能把它的证据等级从【逆向推断】/【官方示例】升为【实测】（真机回传）。
