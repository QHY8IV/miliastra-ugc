# 容器与 protobuf 约定

## 1. 容器

```
偏移   长度  含义
0x00   4     文件长度 − 4（不含末尾 4 字节尾标）
0x04   4     版本号，恒为 1
0x08   4     头标 0x00000326      ← 游戏严格校验
0x0C   4     文件类型：1=.gip 2=.gil 3=.gia 4=.gir
0x10   4     载荷长度 = 文件长度 − 24
0x14   N     载荷（protobuf，UTF-8 字符串）
末尾   4     尾标 0x00000679      ← 游戏严格校验
```

全部大端序。【官方示例】50 个样本（48 个 .gil、2 个 .gia）100% 符合。
【第三方】script-1024 的文档还指出：版本号改成别的值也能加载但建议保持 1；头标/尾标写错会被拒绝加载。
最小的合法 `.gia`（空载荷，能过校验但不会出现任何资产）就是这 24 字节：

```
00 00 00 14  00 00 00 01  00 00 03 26  00 00 00 03  00 00 00 00  00 00 06 79
```

实现：`scripts/lib/container.mjs`（`parseContainer` / `buildContainer`）。

## 2. protobuf 约定

- 线格式：varint / 定长 32 / 定长 64 / 长度前缀；**没有 group**。
- 【官方示例】游戏写出的 protobuf 是**规范**的：字段号升序、重复字段相邻、**从不写默认值 0**（对 23 万个消息实测）。
  所以 schema 覆盖到的部分，“解码 → 编码”能字节级还原；我们的编码器也按同样的规范写。
- 浮点是 32 位（`float`）：坐标、缩放等。
- 大量 500 号以上的字段号（501、502…）出现在界面控件、结构体定义等较新的数据里，是同一种"带类型标签的属性记录"风格。
- 空的嵌套消息在线上是「字段号 + 长度 0」，**和字段缺省是两回事**（解码结果里 `{}` 与缺键不同），不要随手删。

## 3. 工具输出的 JSON 怎么读

`gi.mjs json` 输出：

```json
{ "$format": "miliastra-gi/1", "kind": "gil", "version": 1, "root": { … } }
```

`root` 是按 schema（`schema/gia.proto`、`schema/gil.proto`）解码的对象：

| 情况 | 表示 |
|---|---|
| schema 里有名字的字段 | 用字段名做键；`repeated` 是数组；只出现过的字段才有键（不补默认值） |
| 32 位整数、枚举 | number；有名字的枚举写成名字字符串（如 `"resource_class": "ENTITY_NODE_GRAPH"`），写回时名字或数字都接受 |
| 64 位整数 | 在 ±2^53 内是 number，超出是十进制字符串；写回时 number / 字符串都接受 |
| `bytes` | `"0x…"` 十六进制字符串 |
| **schema 里没有的字段** | 放进该对象的 `_u` 数组，**原样无损保留** |

`_u` 里每条记录：

```
{ "f": 字段号, "w": "varint", "v": 数 }
{ "f": 字段号, "w": "i32" | "i64", "hex": "0x…" }          32/64 位定长（可能是 float，dump 里会给出 float 解读）
{ "f": 字段号, "w": "len", "msg": [ …同样的记录… ] }        嵌套消息（只有「结构化后字节完全一致」才这样展开）
{ "f": 字段号, "w": "len", "text": "…" }                    可读文本
{ "f": 字段号, "w": "len", "hex": "0x…" }                   其它
```

编码时优先级 `msg` > `hex` > `text`，所以你可以放心把一段未知结构里的 `text` 改掉再写回。
**编码器会按字段号排序输出**，所以数组里插入元素、增删字段都不用操心顺序；但 `_u` 里 `msg` 列表内部的顺序是原样写回的。

## 4. 路径

`gi.mjs dump / json / patch` 的 `--path`：

```
node_graphs.graphs[2].graph.nodes[0]     已知字段用名字，[i] 是数组下标
#15[0]                                   未知字段用 #字段号，[i] 是该字段号第几次出现
#9[0].#502[21].#505[3]                   可以混用，逐层往下
```

## 5. 工具分工

| 脚本 | 作用 |
|---|---|
| `scripts/lib/wire.mjs` | 无损线格式编解码 |
| `scripts/lib/proto.mjs` | 极简 .proto 解析器（只支持本技能 schema 用到的语法） |
| `scripts/lib/codec.mjs` | schema ⇄ JS 对象，未知字段无损保留 |
| `scripts/lib/container.mjs` | 容器头尾 |
| `scripts/lib/check.mjs` | 静态检查规则 GG*** |
| `scripts/gi.mjs` | 命令行入口 |
| `scripts/check-gia-gil.mjs` | 检查器入口（`--selftest`） |
