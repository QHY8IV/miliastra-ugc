1.概念简述

客户端脚本：挂载在“客户端控件容器”上的 Lua 脚本，可在本地读取和更新客户端控件，监听光标/键盘事件，并通过逐帧更新实现持续变化的界面和玩法逻辑。

客户端控件容器：客户端控件与客户端脚本的运行载体。脚本通过容器节点获取编辑器预置的子控件，并控制其显示、位置、文本与可交互状态。

**例如，点击收集、UI 动画、2D射击等表现型玩法，均可优先通过客户端控件和 Lua 脚本实现。

②圆圈生成事件：圆圈出现的位置不能超过画布边界，否则会出现圆圈只显示一部分、甚至完全出现在屏幕外的情况，需要根据画布宽高与圆圈宽高，计算圆圈能够出现的安全范围。

要做的功能

对应的脚本逻辑

获取圆圈占用范围

使用 GetSizeDelta() 获取圆圈容器或图片控件的宽高

防止圆圈生成到屏幕外

用画布半宽/半高减去圆圈半宽/半高，得到随机坐标最大范围

生成随机位置

使用 math.random() 在安全范围内生成 X、Y 坐标

让视觉与点击区域一起移动

对圆圈容器调用 SetAnchoredPosition(x, y)

代码示例：

--函数作用：根据画布大小和圆圈尺寸，随机生成一个位置并将圆圈移动到该位置。
local function spawnCircle()
	--读取圆圈尺寸，获取“圆圈容器”的宽高
    local circleWidth, circleHeight = circleRoot:GetSizeDelta()

	--计算可移动范围，确保圆圈不会跑出屏幕边界
    local maxX = math.max(Game.canvasWidth * 0.5 - circleWidth * 0.5, 0)
    local maxY = math.max(Game.canvasHeight * 0.5 - circleHeight * 0.5, 0)

	--生成随机坐标
    local x = (math.random() * 2 - 1) * maxX
    local y = (math.random() * 2 - 1) * maxY

	--移动“圆圈容器”到新位置
    circleRoot:SetAnchoredPosition(x, y)
    return true
end

③处理点击事件和加分：在圆圈点击区域上监听【光标点击】事件。成功点击圆圈后，先增加分数并更新文本；如果尚未达到目标分数，就将圆圈移动到新的随机位置。

代码示例：

--函数作用：把当前分数更新到 UI 文本中
local function updateScore()
    scoreText.text = "分数：" .. tostring(Game.score)
end

--函数作用：处理点击事件
local function onCircleClick(_data)
	--检查游戏是否正在运行，如果没有运行，则不处理点击
    if not Game.running then
        return
    end

	--禁用点击检测，更新分数数值和显示
    circleArea.raycastTarget = false
    Game.score = Game.score + 1
    updateScore()

	--判断是否达到游戏目标
    if Game.score >= Game.scoreTarget then
        Game.running = false
        game.ServerSignal("success"):SendSignal()
        return
    end

	--重复调用生成圆圈函数，生成新的圆圈位置
    spawnCircle()

	--重新启用点击检测，允许下一次点击
    circleArea.raycastTarget = true
end
